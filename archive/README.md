# Archived PS2 recompilation experiments

This directory preserves the abandoned PS2 ELF static-recompilation and
console-runtime investigation. It is **not part of the current build**.

The owner selected an original native Windows game engine with Lua kept as
Lua. The archived C, scripts, checkpoint logs, `fastlane/` and legacy
`tools/` are retained in version control for historical research only.
They must not be imported into `native/` or used as a replacement for
genuine playable Ape Escape 3.

No files were deliberately removed by the cleanup. Original relative paths
below this archive mirror the prior repository layout. Git history also
retains their earlier contents.
